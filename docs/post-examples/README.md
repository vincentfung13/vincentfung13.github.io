# Post styling examples

al-folio's sample posts, kept as copy-paste references. This folder is excluded from the site build
(`docs/` is in `exclude:` in `_config.yml`). To see how each one renders, open the live demo:
https://alshedivat.github.io/al-folio/blog/

Some examples point at sample assets (images, notebooks, chart JSON) that were removed from this repo,
so copy the syntax, not the asset paths.
